## 五、方法论沉淀

### 1. 补天平台数据接口（逆向自 JS）
- **项目列表**: `POST /Reward/pub {name, p}` → POST 分页失效（p 被忽略）
- **正确翻页**: `GET /Reward/pub?name=&p=N` → 每页 30，共 5,994 个（count 字段=200 是 bug）
- 项目详情/提交页需登录（奇安信统一登录，手机号）

### 2. 官网域名解析链路（v4.3 脚本）
```
公司名 → 核心词提取（去城市前缀+公司后缀）→ 必应RSS多轮搜索
→ 域名黑名单过滤 → 拼音相关性打分（pypinyin）→ 标题验证（中文词+拼音）
→ 停放页过滤（for sale/premium/domain/出售）
```

### 3. 关键经验
- **必应 RSS 端点**（`format=rss`）服务器 IP 直连无反爬；HTML 版触发验证码
- **百度 IP 限流**（~50 次后返回空页）；360 首次可用后被限流；DDG 返回 202
- **搜索词策略**: 核心词（不带"官网"）命中率最高；机构类（大学/局/院）用全名
- **小公司（无网络知名度）必应无收录** → 需 ICP 备案查询或登录补天获取
- **拼音域名验证有大量停放页假阳性** → 必须过滤售卖关键词
