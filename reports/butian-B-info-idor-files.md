# 漏洞报告 B：info.sunoasis.com.cn 隐藏文档详情接口越权访问与受保护本地文件匿名下载

> 提交形态说明：本报告与 PbootCMS API 鉴权缺陷（报告 A）根因不同、系统不同，独立提交。
> 依据证据边界原则，本报告**不包含**任何内部文档文件本体、完整下载路径或全量文档清单；
> 敏感性证明仅以文件指纹（MD5）、页数与脱敏后的局部标识呈现。

| 受影响资产 | `info.sunoasis.com.cn`（特变电工新疆新能源股份有限公司资料中心/文档平台） |
| 漏洞类型 | CWE-639（授权绕过：ID 可预测）+ CWE-732（关键资源错误权限分配，storage 目录无鉴权）+ CWE-538（文件和目录信息泄露） |
| 危害等级 | **中危至高危候选**（元数据越权为中危；因确认 1 份明确标注「内部资料 请勿外传」的 42 页手册文件本体可匿名获取，建议平台按其实际敏感性裁量） |

## 二、漏洞描述

资料中心 `info.sunoasis.com.cn` 的公开列表接口每页仅展示少量文档；实测发现其**详情接口不校验资源归属**——列表中不可见的文档，只要按 ID 枚举详情接口即可完整读取标题、编号、外发链接等元数据。

进一步发现：部分文档的详情返回值携带站内存储直链 `/backend/storage/files/<32位十六进制>.<扩展名>`，该存储路径**无任何鉴权校验**，文件本体可直接匿名下载。

两个缺陷组合后，攻击者可从"不可见的文档列表"出发系统性获取隐藏文档的元数据乃至文件本体。

## 三、影响一：隐藏文档详情越权读取

```http
POST /backend/v1/detail HTTP/1.1
Content-Type: application/json

{"filesId": <N>}
```

- 公开列表可见文档约 40 篇；
- 按 ID 枚举详情接口实测可达 **119 篇列表不可见文档**（含内部方案介绍、产品资料等），均返回完整元数据（标题/编号/外发链接/统计字段）。

其中 53 篇携带指向企业文档云的外发链接。此类链接的匿名预览页可渲染文件名、大小、版本、分享人姓名等元数据；全文预览需登录会话，本次测试未验证亦未尝试突破。

## 四、影响二：受保护本地文件匿名下载

```http
POST /backend/v1/detail {"filesId":115}
→ data.file: /backend/storage/files/0598****.pdf

GET /backend/storage/files/<hash>.pdf
→ 200 OK, application/pdf, 3,424,952B
```

119 篇隐藏文档中 **13 篇**携带本地文件直链，均可匿名下载。

### 敏感性判定（三重验证）

对 13 个文件逐一做字节级哈希对照（vs 公开列表集合）、全网搜索可得性检查、文件自身标识审查：

| 类别 | 数量 | 判定 |
|---|---|---|
| **内部资料手册**（42 页 PDF，约 3.42MB） | 1 | **敏感性实锤**：首页明确标注「内部资料 请勿外传」；全网搜索无该资料；官网公开渠道无此文件；PDF 内部含编制/校准人真实姓名 |
| 未发布/下线产品外观图（PNG） | 10 | 哈希不在任何公开集合，属未公开营销物料，敏感性较低 |
| 与公开列表字节级相同的画册/单页 | 2 | 冗余暴露，**不计入漏洞危害** |

**取证指纹**（供平台复核，文件本体不上传）：

| 文件 | 大小 | MD5 |
|---|---|---|
| 内部资料手册（组串式逆变器通信调试指导手册 V1.0） | 3,424,952B | `42108b1d1cd9175b4997d844e2a2ca63` |

如需进一步核验，可通过安全通道索取：脱敏的首页局部截图（含「内部资料 请勿外传」标识）、采集时间与环境说明。**原始文件不随本报告提交、不通过任何聊天渠道外发。**

## 五、危害影响汇总

1. **内部资料外泄（最高优先）**：明确标注「内部资料 请勿外传」的技术手册可被任意匿名者下载，且泄露编制/校准人员真实姓名；未发布产品外观图一并暴露；
2. **信息资产管理失效**：大量列表不可见文档可被系统性枚举，暴露文档平台访问控制缺失；
3. **辅助情报价值**：文档编号体系、组织架构线索（人员名）为定向攻击提供基础。

说明：另有约 170 余篇历史港股公告类内容同样可被枚举，因其本属历史合规披露物、保密性弱，**不作为本报告危害论据**，仅在修复时建议一并治理。

## 六、修复建议

1. **立即下架敏感文件**：对 13 篇本地文件逐一评估去留；「内部资料」级文档严禁挂载于公网可达存储；
2. **storage 目录加鉴权**：`/backend/storage/files/` 增加会话/签名校验，或移出 Web 根由后端受控下发；
3. **详情接口补齐授权**：`/backend/v1/detail` 校验资源对匿名用户的可见性，或要求会话令牌；
4. **清理冗余入口**：与公开列表重复的隐藏条目合并去重，消除双入口不一致；
5. **审计外发链接**：53 篇携带企业文档云外发链接的文档复核分享范围是否过宽。
